How to Start
------------
1. cd /vercel/sandbox/website
2. python3 -m http.server 8080
3. Open http://localhost:8080

Quick Customization
-------------------
1. Contact Info → Edit index.html (lines 290-330)
2. Colors → Edit styles.css (lines 12-18)
3. Logo → Add image and update index.html (line 18)
4. Parts → Add more cards in index.html (parts-grid section)
